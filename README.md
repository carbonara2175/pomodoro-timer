# ポモドーロ・テクニックタイマー v2.0

`index.html` をブラウザで開いて使用する、サーバー不要のタイマーです。デスクトップ通知にはHTTPS配信（GitHub Pages等）またはlocalhostを推奨します。

## 操作

- 開始・一時停止・再開に対応します。
- 「休憩へ進む」「休憩スキップ」「次の集中へ」は、実行中・一時停止中・終了待ちのいずれでも使えます。移動先は開始待ちです。
- 集中終了後は00:00で待ち、通知音を約2秒ごとに繰り返します。＋5分・＋10分で同じ集中を延長できます。延長は自動開始し、何度でも追加できます。
- 休憩へ進むと集中回数が確定します。設定された集中時間を満たしたセッションだけ1回加算し、延長では重複加算しません。途中終了も実際の集中時間は残します。
- リセットは現在のタイマーを集中の開始待ちに戻します。実績は消しません。完了条件を満たした集中をリセットで終了した場合も1回記録します。
- 長い休憩は初期設定ON・15分です。設定でOFFまたは20分・30分に変更できます。セット内4回の完了で長い休憩に進み、長い休憩終了・スキップでセットを更新します。
- 短い休憩・長い休憩には休憩を促す短いメッセージを表示します。

## 設定・保存

設定から標準（25分/5分）、短時間（15分/5分）、長時間（50分/10分）を選べます。変更は次のステップから適用され、進行中・一時停止中の残り時間は変えません。

端末のローカル日付ごとに、完了回数と実際に進行した集中時間を自動保存します。集中時間は小数秒の精度で内部保存し、通常表示は時間・分、TEST表示は秒です。日付をまたぐ集中時間は深夜で分割します。休憩・一時停止・終了後の待機時間は加算しません。

保存キーは `pomodoro-v2`。構造は `version`、`settings`、`days`（日付→`completed`・`focusSeconds`）、`setCount`、`session` です。過去の日付は保持し、設定変更でも削除しません。

再起動すると当日の実績・設定・セッションを復元し、実行中だったタイマーは一時停止状態で復元します。閉じていた時間は加算しません。ブラウザ内保存なので同じ端末・ブラウザ・配信元で使用してください。ブラウザのサイトデータ削除で記録も消えます。保存不可の場合は画面に表示します。複数タブでの同時使用には対応していません。

バックグラウンドやスリープ復帰は時計の経過時間から補正し、現在のカウントダウンの終了までだけ計上します。次のステップを自動開始しません。OSやブラウザが停止している間は終了通知が復帰時まで遅れる場合があります。

## TESTモード

TESTボタンで切り替えます。集中10秒、短い休憩5秒、延長5秒・10秒、長い休憩15秒・20秒・30秒です。プリセットの選択・保存も検証できます。

TEST実績はメモリ内の別記録で、本番の日別記録には加算しません。通常モードに戻ると本番セッションを一時停止状態で復元します。TEST記録はモード終了・再読み込みで初期化します。設定は両モード共通で保存されます。

検証例：集中終了→5秒延長→10秒延長→休憩へ→休憩スキップ。4回の集中終了で長い休憩、スキップ後も5回・6回と増えます。一時停止・途中終了・再読み込みで記録と残り時間も確認できます。

## 通知・小窓表示

最初の開始時に通知許可を要求します。許可済みの場合は各タイマー終了につき1回デスクトップ通知を表示します。通知クリックは既存ウィンドウへのフォーカスを試みます。通知拒否・非対応でもタイマーは動作します。

通知音はWeb Audio APIで生成します。延長・ステップ切り替え・リセット・TEST切り替えで繰り返し音と再生中の音を停止します。音量・通知表示はブラウザとOS設定にも依存します。

高さ650px以下はコンパクト表示になり、残り時間を優先します。TEST状態は小窓でもモード名に表示します。設定は必要なときだけ開けます。

## ファイル

- `index.html`：画面
- `style.css`：通常・コンパクト表示
- `script.js`：状態管理、時間記録、保存、通知

外部ライブラリ・音声ファイルは不要です。
