# ポモドーロ・テクニックタイマー v1.1

## 概要

仕事や勉強のための「25分の集中」と「5分の休憩」を、利用者が確認しながら切り替えるシンプルなWebタイマーです。パソコン、タブレット、スマートフォンのブラウザで使用できます。

## v1.1の変更点

集中と休憩の区切りを明確にするため、次のモードを自動では始めず、利用者の確認を待つようになりました。

- 集中終了後に自動で休憩を開始しない
- **休憩を開始**を押してから休憩タイマーが始まる
- 休憩終了後も**集中を開始**を押してから次の集中が始まる
- 切替待ち中は通知音が繰り返し鳴る
- 次のモードを開始すると通知音が停止する
- TESTモードでも切替動作を確認できる

## 主な機能

- 25分の集中タイマーと5分の休憩タイマー
- 集中と休憩の確認付き切り替え
- 開始、一時停止、途中からの再開、リセット
- 集中を完了した回数の表示（`🍅 0 / 4`〜`🍅 4 / 4`）
- モード切り替え時の短い通知音（外部音声ファイルは不要）
- 集中は赤、休憩は緑を基調にした分かりやすいモード表示
- ブラウザのタブに残り時間とモードを表示
- 集中10秒・休憩5秒で一連の動作を確認できるTESTモード
- パソコン、タブレット、スマートフォンに対応したレスポンシブデザイン

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ名、タイマー、進捗、ボタンなど、画面の内容と順番を定義します。 |
| `style.css` | 色、文字サイズ、余白、スマートフォン向けレイアウトなど、画面の見た目を整えます。 |
| `script.js` | カウントダウン、ボタン操作、切替待ち、回数表示、繰り返し通知音を動かします。 |

追加のライブラリや画像、音声ファイルは使用していません。

## 使い方

1. `index.html` をブラウザで開きます。初期状態では「集中」と「25:00」が表示されます。
2. **開始**を押すと、残り時間が1秒ずつ減ります。
3. **一時停止**を押すと、その時点で止まります。**開始**をもう一度押すと、残り時間から再開します。
4. **リセット**を押すと、集中モードの25:00と完了回数0に戻ります。
5. 集中が終わると00:00で停止し、集中完了回数が1増えて通知音が繰り返し鳴ります。**休憩を開始**を押すと通知が止まり、5分の休憩が始まります。
6. 休憩が終わると再び00:00で停止します。**集中を開始**を押すと通知が止まり、次の25分の集中が始まります。

## TESTモードの使い方

1. **TEST**を押すとTESTモードに切り替わり、画面に「TEST MODE」と表示されます。タイマーと完了回数はリセットされ、集中10秒から始まります。
2. **開始**を押すと、集中10秒の終了後に切替待ちになります。**休憩を開始**を押すと休憩5秒が始まり、その終了後は**集中を開始**を押すまで待機します。完了回数、繰り返し通知音、ブラウザタブ表示も通常モードと同様に確認できます。
3. もう一度**TEST**を押すと通常モードに戻り、タイマーと完了回数がリセットされて集中25:00になります。

モードを切り替えると実行中のタイマーも停止します。切り替え後は、必要に応じて**開始**を押してください。

## 通知音について

通知音はブラウザの **Web Audio API** を使って作っています。切替待ち中は短い音が約2秒間隔で鳴り、次モードの開始またはリセットで停止します。ブラウザの仕様により、最初にユーザー操作を行うまで通知音が利用できない場合があります。このアプリでは**開始**ボタンを押したときに音声機能を準備します。

端末が消音設定になっている場合、ブラウザの自動再生制限がある場合、またはWeb Audio APIに対応していない場合は音が鳴らないことがあります。音が聞こえないときは、端末とブラウザの音量・サイト設定を確認してください。画面の色、モード名、メッセージも同時に変わるため、音が鳴らなくても切り替えを確認できます。

## GitHub Pagesで公開する

このアプリはサーバー処理を必要としないため、GitHub Pagesでそのまま公開できます。

1. この4ファイルをGitHubリポジトリのルート（いちばん上の階層）へ置き、プッシュします。
2. GitHubのリポジトリで **Settings** → **Pages** を開きます。
3. 公開元として対象のブランチと `/ (root)` を選び、保存します。
4. 表示された公開URLへアクセスします。
